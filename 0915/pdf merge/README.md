# PDF 파일 병합기 (PDF Merger)

여러 개의 PDF 파일을 간편하게 업로드하고 하나의 문서로 병합하여 다운로드할 수 있는 웹 애플리케이션입니다[cite: 5].

## 주요 기능
- **다중 파일 선택**: 여러 개의 PDF 파일을 한 번에 또는 순차적으로 업로드 가능[cite: 5]
- **파일 목록 관리**: 업로드된 파일 리스트 확인 및 개별 항목 삭제 기능 제공
- **클라이언트 사이드 처리**: 별도의 서버 전송 없이 브라우저 환경(`pdf-lib`)에서 안전하고 빠르게 PDF 병합 수행[cite: 5]
- **자동 다운로드**: 병합이 완료되면 `merged_document.pdf` 파일명으로 자동 다운로드 링크 생성

## 기술 스택
- **HTML5 / CSS3**: 반응형 사용자 인터페이스 및 파일 드롭/리스트 레이아웃 구현
- **JavaScript (Vanilla)**: 파일 상태 관리 및 이벤트 제어
- **PDF-Lib**: 브라우저 기반 PDF 로드, 페이지 복사 및 병합 처리

## 파일 구성
- `index.html`: UI 및 PDF 병합 로직이 모두 포함된 단일 웹 페이지 파일
- `README.md`: 프로젝트 설명 문서
