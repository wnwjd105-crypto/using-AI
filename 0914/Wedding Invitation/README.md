# 모바일 청첩장 웹 앱 (Mobile Wedding Invitation)

스마트폰 환경에 최적화된 레이아웃과 실시간 카운트다운 애니메이션이 탑재된 모바일 청첩장 웹 페이지입니다.

## 📁 폴더 구조 및 파일 배치 방법
프로젝트 루트 폴더 안에 아래와 같이 파일과 디렉터리를 구성해 주세요.

```text
my-wedding/
├── index.html       # 위 제공된 웹 페이지 전체 소스코드 파일
├── 문구.txt         # 청첩장에 들어갈 인사말 텍스트 파일
└── pictures/        # 사진을 보관하는 폴더
    ├── photo1.jpg   # 메인 커버 사진 (상단 대표 이미지)
    ├── photo2.jpg   # 갤러리 사진 1
    └── photo3.jpg   # 갤러리 사진 2
