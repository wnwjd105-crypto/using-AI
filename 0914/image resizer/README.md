# 🖼️ Smart Image Resizer

> 사용자의 브라우저 안에서 안전하고 빠르게 이미지를 일괄 리사이징하고, 패딩(여백) 또는 크롭(잘라내기) 처리를 할 수 있는 클라이언트 사이드 웹 애플리케이션입니다.

---

## ✨ 주요 기능

* **🔒 프라이버시 보장 (Client-Side Processing)**: 모든 이미지 변환 작업은 사용자의 브라우저 내부(HTML5 Canvas)에서 처리되어 서버로 파일이 유출되지 않습니다.
* **📐 다양한 캔버스 비율 지원**: 
  * 기본 제공 비율: `1:1`, `3:4`, `4:3`, `9:16`, `16:9`
  * 사용자 정의: 가로/세로 비율을 직접 입력하는 **커스텀 비율** 지원
* **🎨 2가지 편집 모드**:
  * **패딩(Padding)**: 원본 이미지를 전부 보존하며 부족한 영역을 여백으로 채움 (여백 배경색 커스텀 지정 가능)
  * **크롭(Crop)**: 선택한 비율에 맞춰 넘치는 이미지를 자동으로 잘라내어 화면을 꽉 채움
* **📊 다중 파일 처리 및 실시간 프로그레스 바**: 여러 장의 이미지를 동시에 업로드할 수 있으며, 썸네일과 개별 프로그레스 바를 통해 진행 상황을 실시간으로 확인 가능
* **📥 개별 및 일괄 다운로드**: 개별 사진 다운로드뿐만 아니라, 작업이 모두 완료되면 **JSZip**을 이용해 한 번에 ZIP 압축 파일로 일괄 다운로드 지원

---

## 🛠️ 사용 기술 (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (ES6+, Canvas API)
* **Libraries**:
  * [JSZip](https://stuk.github.io/jszip/): 다중 처리된 이미지 파일들의 ZIP 일괄 압축
  * [FontAwesome](https://fontawesome.com/): UI 아이콘

---

## 🚀 시작하기 (How to Run)

별도의 백엔드 서버 구축이나 복잡한 설치 과정 없이 단일 HTML 파일로 실행할 수 있습니다.

1. 저장소의 코드를 `index.html` 파일로 저장합니다.
2. 프로젝트 폴더 내에 로고 이미지 파일명(`logo.png`)을 위치시킵니다. (선택 사항)
3. `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 등 모던 웹 브라우저로 엽니다.

---

## 💡 사용 방법

1. 화면 좌상단의 로고를 클릭하면 **NanaLab**(`https://nanalab.kr`) 사이트로 이동합니다.
2. 상단 설정 패널에서 원하는 **캔버스 비율**, **처리 방식(패딩/크롭)**, 필요시 **여백 배경색**을 설정합니다.
3. 드래그 앤 드롭 영역 또는 **[파일 선택하기]** 버튼을 통해 이미지 파일을 업로드합니다.
4. 실시간으로 차오르는 프로그레스 바를 확인하고, 완료된 개별 파일 다운로드 버튼을 누르거나 모든 작업이 끝난 후 **[일괄 다운로드 (ZIP)]** 버튼을 클릭해 저장합니다.
