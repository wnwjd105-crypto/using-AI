# 오늘의 원소 운세 (Element Fortune Web App)

이 프로젝트는 사용자의 기본 정보(이름, 생일, 성별)와 5대 원소(불, 물, 나무, 땅, 바람) 중 하나를 선택받아, 선택된 원소에 맞는 오늘의 운세를 랜덤으로 출력해 주는 간단한 웹 애플리케이션입니다.

## 주요 기능
- **사용자 정보 입력**: 이름, 생일, 성별 입력 폼 제공
- **원소 선택**: 불, 물, 나무, 땅, 바람 중 하나 선택 가능 (드롭다운)
- **랜덤 운세 생성**: 선택한 원소별 특성에 맞춘 다채로운 오늘의 운세 문구 중 하나를 무작위로 출력
- **반응형 디자인**: 모바일과 데스크톱 환경 모두에서 깔끔하게 보일 수 있도록 CSS 스타일링 적용

## 기술 스택
- **HTML5**: 구조 설계
- **CSS3**: 스타일링 및 반응형 중앙 정렬 배치
- **JavaScript (Vanilla)**: 폼 이벤트 처리 및 랜덤 운세 로직 구현

## 파일 구성
- `index.html`: 프론트엔드 UI 및 로직이 모두 포함된 단일 웹 페이지 파일
- `README.md`: 프로젝트 설명 문서
