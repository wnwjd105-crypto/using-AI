# TextRank 문서 요약 웹 앱 (Document Summarizer)

PDF 및 DOCX 문서 파일을 업로드하면 브라우저 내에서 직접 텍스트를 추출하고, **TextRank 알고리즘**을 적용하여 가장 핵심이 되는 문장들을 요약해 주는 웹 애플리케이션입니다. 슬라이더를 통해 최소 1문장에서 최대 5문장까지 원하는 분량을 자유롭게 조절할 수 있습니다.

## 주요 기능
- **다양한 파일 형식 지원**: PDF(`pdf.js`) 및 Word 문서(`.docx`, `mammoth.js`) 파일 업로드 및 텍스트 자동 파싱
- **TextRank 알고리즘 구현**: 외부 서버 전송 없이 브라우저 환경에서 순수 자바스크립트로 문장 간 유사도를 계산하고 핵심 랭킹 산출
- **동적 분량 조절 슬라이더**: 1문장부터 5문장까지 사용자가 원하는 요약 분량 실시간 지정 가능
- **원문 순서 정렬 요약**: 중요도가 높은 문장들을 선별한 뒤, 문서 흐름에 맞게 원래 순서대로 자연스럽게 배치하여 리스트 형태로 출력

## 기술 스택
- **HTML5 / CSS3**: 모던한 디자인 및 반응형 UI 레이아웃
- **JavaScript (Vanilla)**: 텍스트 토큰화, 그래프 가중치 산출 및 TextRank 반복 연산 로직 구현
- **PDF.js & Mammoth.js**: 클라이언트 사이드 문서 파싱 라이브러리 연동

## 파일 구성
- `index.html`: UI 인터페이스, 파싱 엔진, TextRank 요약 알고리즘이 모두 포함된 단일 웹 페이지 파일
- `README.md`: 프로젝트 설명 문서
