# BMI 및 목표 체중 계산기 (BMI & Target Weight Calculator)

사용자의 성별, 키, 몸무게를 입력받아 현재 BMI를 산출하고, 맞춤형 건강 기준(BMI 90, 100, 110에 대응하는 목표 체중 수치)에 도달하기 위해 몇 kg을 감량 혹은 증량해야 하는지 직관적으로 보여주는 웹 애플리케이션입니다.

## 주요 기능
- **입력 폼**: 성별(남성/여성), 키(cm), 현재 몸무게(kg) 입력 기능
- **BMI 산출**: 현재 체형의 BMI 지수를 소수점 둘째 자리까지 계산
- **목표 기준별 비교 (90, 100, 110)**: 
  - 기준 90 (BMI 18.5 기준): 저체중 방어 및 슬림 체형 기준
  - 기준 100 (BMI 22.0 기준): 대한민국 표준 건강 체중 기준
  - 기준 110 (BMI 25.0 기준): 과체중 및 비만 경계 기준
- **증감량 가이드**: 목표 체중에 도달하기 위해 구체적으로 몇 kg을 빼거나 찌워야 하는지 색상 강조 표시

## 기술 스택
- **HTML5 / CSS3**: 모던하고 깔끔한 카드형 반응형 UI 디자인
- **JavaScript (Vanilla)**: BMI 산출 로직 및 실시간 결과 렌더링 연동
