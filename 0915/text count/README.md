# 글자수 및 바이트 계산기 (Character & Byte Counter)

입력된 텍스트의 글자수와 바이트 수를 실시간으로 계산해 주는 웹 애플리케이션입니다. 
사용자의 요청에 따라 **한글 한 글자를 2바이트**로 계산하는 로직을 적용하였습니다.

## 주요 기능
- **실시간 입력 감지**: 텍스트를 입력하거나 수정할 때 즉시 계산 결과 반영
- **공백 포함/제외 글자수**: 전체 글자수와 공백을 제외한 순수 글자수 계산
- **바이트(Byte) 계산**: 한글은 2바이트, 영문/숫자/기호/공백은 1바이트로 계산 (EUC-KR/CP949 기준)
- **반응형 UI**: 깔끔하고 직관적인 카드형 레이아웃 제공

## 기술 스택
- **HTML5**: 구조 설계
- **CSS3**: 스타일링 및 그리드 레이아웃
- **JavaScript (Vanilla)**: 실시간 입력 이벤트 처리 및 유니코드 기반 바이트 산출 로직

## 파일 구성
- `index.html`: 프론트엔드 UI 및 계산 로직이 포함된 단일 파일
- `README.md`: 프로젝트 설명 문서
