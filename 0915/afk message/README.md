# 자리비움 안내 화면 (Away Message Display App)

잠시 자리를 비울 때 모니터나 화면에 띄워두고 현재 일정, 복귀 예정 시간, 실시간 카운트다운 및 안내 문구를 깔끔하고 아름다운 애니메이션 그라데이션 배경과 함께 표시해 주는 웹 애플리케이션입니다.

## 주요 기능
- **입력 폼 제공**: 일정, 복귀 예정 시간, 기타 안내 문구를 간편하게 입력
- **아름다운 애니메이션 그라데이션**: 부드럽게 흐르는 다중 색상 그라데이션 배경 적용
- **시각적 강조 디자인**: 사용자가 입력한 일정을 가장 큰 타이포그래피(글자 크기)로 시원하게 표기
- **실시간 카운트다운**: 복귀 예정 시간까지 남은 시·분·초를 1초마다 실시간으로 갱신하여 표시
- **반응형 대형 카드 UI**: 글래스모피즘(Glassmorphism) 효과를 적용한 모던한 카드형 레이아웃

## 기술 스택
- **HTML5**: 구조 설계
- **CSS3**: CSS 애니메이션 그라데이션, 블러 효과(backdrop-filter), 반응형 스타일링
- **JavaScript (Vanilla)**: 폼 입력값 제어, 화면 전환 효과, 실시간 카운트다운 타이머 연동

- `README.md`: 프로젝트 설명 문서
