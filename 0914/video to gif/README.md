# 🎬 Video to GIF

> 사용자의 브라우저 안에서 동영상 파일을 간편하게 GIF 애니메이션으로 변환할 수 있는 클라이언트 사이드 웹 애플리케이션입니다.

---

## ✨ 주요 기능

* **🔒 프라이버시 보장 (Client-Side Processing)**: 모든 동영상 프레임 추출 및 GIF 인코딩 작업은 사용자의 브라우저 내부에서 처리되어 서버로 파일이 유출되지 않습니다.
* **⚡ 29 FPS 성능 제한**: 과도한 시스템 부하를 방지하기 위해 **최대 29 FPS**로 프레임 추출을 제한하여 안정적인 변환을 지원합니다.
* **📊 실시간 썸네일 및 프로그레스 바**: 업로드한 동영상의 썸네일과 함께 파일별 독립적인 진행 상황을 실시간 프로그레스 바를 통해 확인할 수 있습니다.
* **📥 간편한 다운로드**: 변환 작업이 100% 완료되면 활성화되는 다운로드 버튼을 클릭해 생성된 GIF 파일을 즉시 저장할 수 있습니다.

---

## 🛠️ 사용 기술 (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Libraries**:
  * [gifshot](https://github.com/yahoo/gifshot): 자바스크립트 기반 동영상/이미지 프레임 GIF 인코딩 라이브러리
  * [FontAwesome](https://fontawesome.com/): UI 아이콘

---

## 🚀 시작하기 (How to Run)

별도의 백엔드 서버 구축이나 복잡한 설치 과정 없이 단일 HTML 파일로 실행할 수 있습니다.

1. 저장소의 코드를 `index.html` 파일로 저장합니다.
2. 프로젝트 폴더 내에 로고 이미지 파일명(`logo.png`)을 위치시킵니다. (선택 사항)
3. `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 등 모던 웹 브라우저로 엽니다.

---

## 💡 사용 방법

1. 화면 좌상단의 로고를 클릭하면 **NanaLab**(`https://nanalab.kr`) 사이트로 이동합니다.
2. 드래그 앤 드롭 영역 또는 **[동영상 선택하기]** 버튼을 통해 동영상 파일(`MP4`, `MOV`, `WEBM` 등)을 업로드합니다.
3. 파일 목록에 생성된 썸네일과 프로그레스 바를 통해 변환 진행 상황을 확인합니다.
4. 변환이 완료되어 활성화되는 **다운로드 버튼**을 눌러 완성된 GIF 애니메이션을 저장합니다.
