# 📚 교육 과정 안내 및 만족도 설문조사

진행되는 교육 과정에 대한 커리큘럼 소개와 학습자 피드백을 수집하기 위한 웹앱입니다.

## 📌 주요 기능
- **커리큘럼 요약:** 교육 개요, 주차별 목표 및 강의 자료 안내
- **설문조사 기능:** 교육 만족도, 난이도 평가, 건의사항 작성
- **자동 데이터화:** 설문 응답을 구글 스프레드시트에 실시간 기록
