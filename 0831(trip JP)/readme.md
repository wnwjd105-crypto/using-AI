# 🇰🇷 日本人旅行客向け 韓国旅行ガイド (방한 일본인 가이드)

한국을 방문하는 일본인 여행객을 위한 주요 여행 정보 및 편의 기능을 제공하는 웹앱입니다.

## 📌 주요 기능
- **한국 여행 기초 안내:** 대중교통 이용법(T-money), 긴급 연락처, 기본 에티켓
- **간단 여행 회화:** 자주 쓰는 필수 한국어 표현 및 일본어 발음 표기
- **위치/장소 추천:** 주요 관광지 및 주변 편의시설 안내
