知っておきたい交通の基本 3箇条

スムーズな移動のために、まずこの3つのポイントを押さえましょう

💳
Point 01: 必須アイテム

T-money (티머니 / 交通カード) 購入場所

空港、コンビニ（CU・GS25・セブンイレブン）、地下鉄駅の券売機で購入可能です。

⚠️ 重要注意点: カードチャージ (충전 / チュンジョン) は「韓国ウォンの現金のみ」可能です。クレジットカードではチャージできないため、事前に現金を準備しましょう。
🔄
Point 02: お得な制度

환승 할인 (ファンスン ハリン / 乗換割引) 30分以内

地下鉄 ⇄ バス、バス ⇄ バスを30分以内（21時〜翌朝7時は60分以内）に乗り換えると、初乗り運賃が重複せず距離に応じた少額加算のみで乗車できます（最大4回まで乗換可能）。

⚠️ 重要注意点: 下車時にも必ずカードリーダーにタッチ (하차 태그 / ハチャタグ) してください。タッチせずに降りると割引が無効になります。
📱
Point 03: 必携アプリ

막차 (マクチャ / 終電) & おすすめ地図アプリ

韓国ではGoogleマップの徒歩ルート検索が制限されています。現地移動には次の2つのアプリが必須です。

  • NAVER Map (네이버 지도): 日本語完全対応。リアルタイムのバス到着時刻や徒歩ナビに最適。
  • Subway Korea (지하철 종결자): 首都圏地下鉄の駅番号検索、最短乗り換え、終電アラームに対応。

지하철 (ジハチョル / 地下鉄) の基本ルールと利用手順

基本初乗り運賃: 1,400ウォン (カード利用時)

💡 乗車の流れ

  1. 改札口のカードリーダーにT-moneyカードをタッチ（残高が表示されます）。
  2. 乗車方向（終着駅や主要乗換駅の名前）と「駅番号」を確認してホームへ進む。
  3. 降車時も改札口のリーダーにタッチして出場。

⚠️ 知っておくべき重要ポイント

  • 改札誤進入（15分以内ルール）: 反対側の改札に間違えて入ってしまった場合、同一駅で15分以内なら反対側の改札にタッチして入り直しても追加運賃は発生しません（同一路線・同乗車駅基準）。
  • 駅出口番号: 韓国の地下鉄は出口番号（1番出口〜）が非常に分かりやすく整備されています。目的地の最寄り出口番号を事前に調べておくと迷いません。
  • エスカレーター＆マナー: 急ぐ人のために左側を空け、右側に立つのが定着しています。車内での通話や大声での会話は控えましょう。

시내버스 (シネボス / 市内バス) の色別系統とルール

幹線バス初乗り運賃: 1,500ウォン (カード利用時)

🎨 バスの車体色による違い

  • 青色バス (幹線): ソウル市内の主要幹線道路を結ぶ長距離移動用。
  • 緑色バス (支線・マウル): 地下鉄駅と住宅街・近隣エリアを結ぶ地域巡回用。
  • 赤色バス (広域): ソウルと京畿道（水原、板橋、一山など）を結ぶ高速バス。
  • Nバス (深夜オルペミ): 23:30〜翌06:00運行の深夜専用バス。

🚫 車内持ち込み厳禁ルール

蓋なし飲料の持ち込み禁止 (테이크아웃 금지): ストローが刺さったカップコーヒーやタピオカミルクティーなど、こぼれる恐れのある持ち帰り飲料を持っていると乗車を拒否されます。密閉されたペットボトルや水筒のみ持ち込み可能です。
  • 乗車・降車のドア: 前扉（前ドア）から乗車してカードタッチ、後扉（中央ドア）から降車してカードタッチします。
  • 降車ベル (하차벨 / ハチャベル): 降りる停留所のアナウンスが流れたら、あらかじめ赤いベルを押しておきましょう。

택시 (テクシ / タクシー) の種類と安全な乗り方

一般タクシー初乗り運賃: 4,800ウォン (深夜割増あり)

🚖 タクシーの種類

  • 一般タクシー (オレンジ/シルバー/白): 最も一般的で安価。深夜22:00〜翌04:00は20%〜40%の深夜割増（야간할증 / ヤガンハルチュン）が適用。
  • 模範タクシー (모범택시 / 黒色・金帯): ベテランドライバー、車両が大型で清潔。初乗り7,000ウォン。
  • 大型・インターナショナルタクシー: 外国語対応可能な事前予約制タクシー。

🛡️ トラブル防止チェック

  • メーター確認: 発車時にメーター（미터기 / ミトギ）が作動しているか確認。交渉による定額請求は違法です。
  • 支払いはT-moneyまたはクレカ: 現金がなくてもT-moneyカードまたは国際クレジットカード（VISA/Mastercard等）で決済可能。
  • 領収書 (영수증 / ヨンスジュン) を必ずもらう: 車内に忘れ物をした際、領収書に記載された車両番号と会社電話番号で即座に問い合わせができます。
Popular Spots

主要観光地への地下鉄アクセスガイド

日本人旅行者に人気の4大エリアへの最寄り駅、路線、おすすめ出口番号をまとめました。

명동 (明洞 / ミョンドン) - コスメ・両替・屋台グルメの聖地

4号線 明洞駅 (424) 2号線 乙支路入口駅 (202)

🚶 おすすめ最寄り出口

  • 4号線 明洞駅 6番出口: メインストリート直結！コスメ通りや屋台街へすぐ。
  • 4号線 明洞駅 8番出口: 明洞餃子や南山オルミ（Nソウルタワー行きエレベーター）方面。
  • 2号線 乙支路入口駅 5・6番出口: ロッテ百貨店本店や免税店へのアクセス至便。

✈️ 仁川空港からのアクセス

空港鉄道A'REX（一般列車）で「ソウル駅」まで乗車（約59分） ➔ 地下鉄4号線に乗換えて2駅（約4分）で明洞駅到着。乗り換えも非常にスムーズです。

홍대 (弘大 / ホンデ) - 若者カルチャー・ファッション・カフェの街

2号線 弘大入口駅 (239) 空港鉄道 A'REX 京義・中央線

🚶 おすすめ最寄り出口

  • 9番出口: 弘大一番の待ち合わせ定番スポット！歩行者天国・ショップ通りへ直結。
  • 3番出口: 延南洞（ヨンナムドン）の「京義線スッキル公園」やおしゃれなカフェ通り方面。
  • 4番出口: AK&弘大ショッピングモール直結、空港鉄道改札から最寄り。

✈️ 仁川空港からのアクセス

空港鉄道A'REX（一般列車）で乗換なし直通約50分で弘大入口駅に到着！初日や最終日の滞在拠点としても抜群の人気を誇ります。

성수 (聖水 / ソンス) - 工場リノベカフェ＆韓国トレンド最前線

2号線 聖水駅 (211) 水仁・盆唐線 ソウルの森駅

🚶 おすすめ最寄り出口

  • 2号線 聖水駅 3・4番出口: カフェ通り（Cafe Onion、Dior聖水ポップアップなど）の中心。
  • 水仁・盆唐線 ソウルの森駅 5番出口: アトリエ通り、SMエンタ本社、ソウルの森散策路方面。

🚆 明洞（乙支路）からのアクセス

地下鉄2号線「乙支路入口駅」から乗車し、内回り方面へ約15分。乗換なしでダイレクトに聖水駅へ到着します。

강남 (江南 / カンナム) - ビル群・美容クリニック・大型ショッピング

2号線 江南駅 (222) 新盆唐線 江南駅

🚶 おすすめ最寄り出口

  • 10番・11番出口: 江南メイン通り！カカオフレンズショップ、映画館、飲食店が密集。
  • 地下街出口: 「江南駅地下ショッピングセンター（地下街）」はプチプラ洋服やスマホケースの宝庫。

🚆 弘大・明洞からのアクセス

弘大入口駅から2号線で約35分。明洞エリア（乙支路入口駅）からは2号線で約30分で到着します。

🧮 運賃計算 & FAQ

km
予想カード運賃: 1,400 ウォン (基本料金内)
※10kmまで1,400ウォン、以降5kmごとに100ウォン加算
T-moneyカードの残高は返金できますか？

はい。コンビニで残高20,000ウォン以下なら手数料500ウォンを引いて即時現金で払い戻し可能です（カード本体代は返金不可）。

子ども料金はどうなりますか？

満6歳〜12歳は「어린이 (オリニ / 小児)」運賃（地下鉄500ウォン、バス550ウォン）。コンビニでパスポートを提示して登録が必要です。

緊急サポート＆盗難・紛失物案内

韓国観光公社 観光通訳案内電話 1330

日本語完全対応・24時間年中無休・通話料無料アプリあり

道に迷ったとき、駅員やタクシー運転手との通訳が必要なとき、観光中のトラブル時にいつでも日本語オペレーターが対応してくれます。

🚓

警察: 112 / 救急・消防: 119

事件・事故・盗難被害は112へ。日本語通訳サービス（三者通話）が提供されます。

🧳

地下鉄・バスで忘れ物をした時の対処法

  1. 地下鉄の場合: 乗っていた列車の「号線・乗車時刻・車両番号（ドア付近の数字）」を確認し、駅事務室または地下鉄遺失物センターへ申告。
  2. タクシーの場合: 領収書に記載された「事業者電話番号」または120タサンコールセンターへ連絡。
  3. 警察庁紛失物ポータル (LOST112): 全国で届け出られた遺失物を検索可能（lost112.go.kr）。
