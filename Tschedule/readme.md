# 📅 동아리 일정 공유 및 모임 조율 웹앱

동아리 부원들의 가능한 시간대를 취합하고 모임 활동을 계획하기 위한 Google Apps Script 기반 조율 웹앱입니다.

## 📌 주요 기능
- **기본 정보 입력:** 학번 및 이름 등록
- **가능 시간대 선택:** 요일 및 시간대별 참여 가능 여부 체크
- **활동 제안:** 모임 시 함께하고 싶은 활동/스터디 주제 자유 제시
- **비고란 운영:** 늦참, 조퇴, 장소 건의 등 특이사항 기재
- **실시간 스프레드시트 집계:** 부원들의 응답 데이터를 실시간으로 취합하여 최적의 모임 시간 도출
