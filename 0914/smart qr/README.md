# Smart QR 웹 애플리케이션

로고와 깔끔하게 어울리는 화사한 밝은 톤 디자인과 감성적인 인터랙티브 그라데이션이 적용된 QR코드 생성 웹 앱입니다.

## 🌟 주요 특징
- **인터랙티브 동적 그라데이션**: 마우스 커서의 움직임에 따라 배경 그라데이션의 색상 톤과 각도가 실시간으로 변화하여 생동감을 줍니다.
- **스마트 UI 전환**: URL을 입력하고 [확인]을 누르면 입력창이 상단으로 이동하고 정중앙에 선명한 QR코드가 나타납니다.
- **분리된 다운로드 버튼**: QR코드 아래에 전용 다운로드 버튼을 배치하여 클릭 한 번에 고화질 JPG 파일로 저장할 수 있습니다.
- **로고 및 브랜딩 연동**: 상단 좌측 `logo.png` 파일과 우측 `Smart QR` 타이틀이 조화롭게 배치되어 있습니다.
