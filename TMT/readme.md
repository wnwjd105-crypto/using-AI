# 🏕️ 팀 MT 안내 웹앱

팀 MT(Membership Training) 일정 안내 및 참가자 신청을 관리하기 위한 Google Apps Script 기반 웹앱입니다.

## 📌 주요 기능
- **일정 및 장소 안내:** MT 상세 타임테이블 및 집결지 정보 제공
- **참가 신청 폼:** 참석 여부, 식음료 선호도, 비상 연락처 수집
- **스프레드시트 실시간 연동:** 참가자 현황 자동 집계 및 정리
