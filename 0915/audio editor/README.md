# 웹 오디오 편집기 (Web Audio Editor)

MP3, WAV 등 다양한 오디오 파일을 업로드하여 브라우저 환경에서 직접 편집하고 변환할 수 있는 웹 애플리케이션입니다.

## 주요 기능
- **오디오 파일 업로드**: 로컬 오디오 파일을 브라우저로 불러와 파형 및 재생 시간 분석
- **구간 트림 (자르기)**: 원하는 시작 초(s)와 종료 초(s)를 지정하여 특정 구간만 추출
- **볼륨 조절**: 0%부터 최대 200%까지 음량 증감 조절 가능
- **포맷 변환**: 편집된 오디오를 무손실 **WAV** 포맷 또는 압축된 **MP3** 포맷으로 선택하여 변환 및 다운로드 지원
- **실시간 미리보기**: 편집 완료 즉시 웹 브라우저 내에서 바로 재생하여 확인 가능

## 기술 스택
- **HTML5 / CSS3**: 반응형 사용자 인터페이스 디자인
- **Web Audio API**: 브라우저 기반 오디오 버퍼 디코딩, 채널 분리, 샘플 기반 트림 연동
- **Lamejs**: 브라우저 환경에서 동작하는 순수 자바스크립트 MP3 인코더 라이브러리

## 파일 구성
- `index.html`: UI 인터페이스 및 오디오 프로세싱/변환 로직이 모두 포함된 단일 웹 페이지 파일
- `README.md`: 프로젝트 설명 문서
