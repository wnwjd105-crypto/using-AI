# 문서 분석기 (PDF & DOCX Document Analyzer)

업로드한 문서(PDF, DOCX)의 텍스트와 요소를 분석하여 글자 수, 단어 수, 공백 개수 및 이미지 개수를 실시간으로 제공하는 웹 애플리케이션입니다.

## 주요 기능
- **파일 업로드**: PDF 및 DOCX 파일 지원
- **텍스트 통계**: 
  - 공백 포함 글자 수
  - 공백 제외 글자 수
  - 총 공백 개수
  - 단어 수 (공백 기준 분할)
- **멀티미디어 분석**: 문서 내 포함된 이미지 총 개수 카운트
- **클라이언트 사이드 처리**: 별도의 백엔드 서버 없이 브라우저에서 안전하게 파일 분석 수행

## 기술 스택
- **HTML5 / CSS3**: 반응형 UI 및 카드 스타일 레이아웃
- **JavaScript (Vanilla)**: 이벤트 처리 및 통계 알고리즘
- **PDF.js**: 브라우저 환경에서의 PDF 텍스트 및 이미지 객체 파싱
- **Mammoth.js**: DOCX 문서 구조 분석 및 텍스트/이미지 추출

## 파일 구성
- `index.html`: UI 구성과 파일 파싱/분석 로직이 모두 포함된 단일 웹 페이지 파일
- `README.md`: 프로젝트 설명 문서
