# 구슬 대포 추첨기 (Marble Cannon Raffle App)

참가자들의 이름을 입력하면 대포에서 구슬들이 차례대로 발사되어, 수많은 장애물(핀) 사이를 무작위로 부딪치며 내려간 뒤 가장 마지막에 결승선에 도착하는 사람을 당첨자로 선정해 주는 재미있는 물리 시뮬레이션 웹 앱입니다.

## 주요 기능
- **자유로운 참가자 입력**: 쉼표(,)나 줄바꿈을 통해 원하는 만큼 인원 추가 가능
- **실시간 물리 엔진 시뮬레이션 (`Matter.js`)**: 중력, 탄성, 충돌 감지를 반영하여 매번 완전히 다른 결과를 도출하는 공정하고 역동적인 추첨 과정
- **대포 발사 연출**: 상단 대포 입구에서 구슬들이 순차적으로 튕겨져 나오며 핀 사이를 통과
- **최종 당첨자 선정**: 장애물 코스를 거쳐 가장 마지막에 들어오는 구슬을 자동으로 판별하여 축하 배너 출력

## 기술 스택
- **HTML5 / CSS3**: 모던하고 직관적인 그라데이션 인터페이스 디자인
- **JavaScript (Vanilla)**: 입력값 처리 및 게임 루프 제어
- **Matter.js**: 2D 강체 물리 엔진 (중력, 핀 충돌, 반발력 구현)
