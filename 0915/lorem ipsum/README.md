# Lorem Ipsum 생성기 (Lorem Ipsum Generator)

슬라이드 바를 조절하여 원하는 길이(최소 10자 ~ 최대 5000자)의 Lorem Ipsum 더비 텍스트를 실시간으로 생성하고 복사할 수 있는 웹 애플리케이션입니다.

## 주요 기능
- **실시간 슬라이더 연동**: 슬라이드 바를 움직이면 기본 150자를 포함하여 최소 10자에서 최대 5000자까지 즉시 글자 수 변경
- **클립보드 복사**: 버튼 클릭 한 번으로 생성된 텍스트를 간편하게 복사
- **반응형 디자인**: 모바일 및 데스크톱 환경 모두에서 깔끔하게 작동

## 기술 스택
- **HTML5**: 구조 설계
- **CSS3**: 스타일링 및 반응형 카드 레이아웃
- **JavaScript (Vanilla)**: 텍스트 반복 생성 알고리즘, 슬라이더 입력 이벤트 및 클립보드 API 연동

## 파일 구성
- `index.html`: UI 및 기능 로직이 포함된 단일 웹 페이지 파일
- `README.md`: 프로젝트 설명 문서
