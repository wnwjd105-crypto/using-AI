# 🍱 점심/저녁 식사 선호도 조사 웹앱

팀원들의 식사 메뉴 선호도 및 투표를 손쉽게 진행할 수 있는 간이 투표 웹앱입니다.

## 📌 주요 기능
- **메뉴 투표:** 점심/저녁 후보 메뉴 선택 및 실시간 투표
- **선호도/제외 항목 수집:** 알레르기, 비선호 식재료 체크
- **중복 제출 방지 및 결과 집계:** 스프레드시트를 통한 빠른 메뉴 확정
